jadi disini menampilkan sebuah program manajemen acara kampus yang sedang dijalankan oleh terminal di dalam editor VS Code. Sistem ini menggunakan bahasa pemrograman Python untuk mengelola basis data kegiatan sederhana dengan berbasis teks. Pengguna dapat memilih berbagai opsi menu seperti menambah, melihat, mengubah, dan menghapus informasi acara. Dalam contoh yang terlihat, seseorang berhasil memasukkan detail acara berupa nama, tanggal, dan lokasi ke dalam sistem. Setelah data disimpan, program mampu menampilkan kembali informasi terdaftar tersebut secara rapi, Secara keseluruhan.
